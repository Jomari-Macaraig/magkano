# apps/api

Hono + TypeScript API. Holds the Drizzle schema and migrations, the domain logic, the scripts under `scripts/` (`extract` now; `tag` and `seed` later) and `data/`.

## Data flow

The committed files under `data/` are the dataset; Postgres is a copy that `seed` wipes and rebuilds. Routes only read from Postgres. The web app reaches routes through Hono RPC types (`AppType`), never by importing server code.

## Run

- `pnpm --filter @magkano/api dev`: `tsx watch` on `src/server.ts`, port `API_PORT` (default 8787), reading the root `.env`.
- `pnpm db:generate` after editing `src/db/schema.ts`; `pnpm db:migrate` to apply. Both read `DATABASE_URL` from the root `.env`.
- `pnpm --filter @magkano/api extract <pdf>`: writes `data/publications/<da|dti>-<date>.json`. See [src/extract/CLAUDE.md](src/extract/CLAUDE.md).
- Tests: `pnpm vitest run --project api`. Route tests call `createApp().request(...)`; extract tests read `sample/`. None need a database.

## Key files

- `src/app.ts`: `createApp()` builds the Hono app under `/api`. Routes are **chained** so `AppType` carries them all for Hono RPC; add new routes the same way (`.route(...)` / `.get(...)`).
- `src/errors.ts`: every error is `{ error, message }`. Codes: 400 `invalid_input`, 404 `not_found` (also unknown routes), 500 `internal` (any thrown error; logged, message hidden). Hono's own 4xx errors, such as a malformed JSON body, also map to 400 `invalid_input`.
- `src/validate.ts`: `validate(target, zodSchema)` middleware. Use it on every input; a failure answers 400 `invalid_input` with `path: message` pairs.
- `src/index.ts`: type-only exports for the web app (`AppType`, `ErrorBody`).
- `src/server.ts`: local Node server.
- `src/db/schema.ts`: the 9 tables. Recipe ids are text (the seed key); other ids are integer identity and change on every re-seed. `recipe_chunks.embedding` is `vector(1536)` with an HNSW cosine index.
- `src/db/client.ts`: `createDb(url)` returns a Drizzle client with `close()`.
- `migrations/`: `0000` is a custom migration enabling `vector`; later ones are generated by drizzle-kit.

## Env

- `DATABASE_URL` (required for migrations and, later, routes that read data).
- `OPENAI_API_KEY` (optional; search falls back to text matching).
- `API_PORT` (optional, default 8787).

No Clerk on the server in v1: every route is anonymous.
